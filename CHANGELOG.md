# История изменений ECLIPSE Unlimited для Android

Здесь собраны пользовательские изменения актуального нативного приложения. Полный архив файлов доступен на странице [релизов](https://github.com/pomah7878-bot/ECLIPSE_VPN_Android/releases).

## 2.7.1 — 2026-11-05

`versionCode 14` · пакет `com.eclipseunlimited.app` · Android 8.0+

**[Скачать с официального сайта](https://eclipse.unlimited.bot.nu/client-update/client.apk)**

### Исправления

- Исправлена изолированная проверка задержки серверов с доменными адресами: конфигурация замера больше не зависит от DNS-модуля, который во время этой проверки отсутствует.
- Боевая VPN-конфигурация не изменена: стратегия разрешения адреса для основного туннеля сохранена.
- Проверка доступности интернета переведена на Cloudflare, чтобы снизить риск ложного отказа проверочного ресурса.

### Проверка

- Unit-тесты и подписанная release-сборка прошли успешно.
- Обновление установлено поверх официальной версии 2.7 с сохранением совместимой подписи.
- На реальном устройстве через мобильную сеть подтверждён HTTPS-запрос через VLESS REALITY: `security=reality`, `network=tcp`.

SHA-256 официального APK:

```text
472c97d035541f5558f01768e883d52574a724f68932eb3968924317d47152dc
```

> Поддержка REALITY подтверждена, но доступность конкретного сервера зависит от сети пользователя. Ошибки handshake в отдельной Wi-Fi-сети при успешном подключении через мобильный интернет могут указывать на внешнюю фильтрацию.
