# Политика конфиденциальности ECLIPSE VPN

Дата обновления: 21 августа 2026

## Что делает приложение

ECLIPSE VPN — клиент для подключения к серверам сервиса ECLIPSE Unlimited
по протоколам VLESS/Reality, Trojan, Shadowsocks и другим. Приложение
является форком открытого проекта [v2rayNG](https://github.com/2dust/v2rayNG)
с изменённым оформлением и адресами серверов.

## Какие данные собирает приложение

Само приложение (клиент):

- **не содержит рекламы, трекеров и аналитики**;
- **не отправляет** данные об использовании, устройстве или трафике
  каким-либо третьим сторонам;
- хранит настройки подключения (адреса серверов, выбранный протокол)
  **локально на устройстве**;
- при проверке обновлений обращается к GitHub (api.github.com) — это
  единственный сетевой запрос, не связанный напрямую с VPN-подключением.

## Данные, необходимые для работы VPN

Чтобы подключиться к серверу, приложению нужна ссылка-подписка, которую
вы получаете в Telegram-боте ECLIPSE Unlimited после оформления доступа.
Эта ссылка содержит адрес сервера и параметры подключения — она не
передаётся приложением никуда, кроме самого VPN-сервера при установке
соединения.

Обработка данных на стороне сервиса ECLIPSE Unlimited (учёт подписки,
трафика, платежей) регулируется отдельно и описана в боте
(@vless_keysvpn_bot) и на сайте сервиса.

## Разрешения приложения

- **VPN-сервис (VpnService)** — необходимо для создания VPN-туннеля,
  основная функция приложения.
- **Уведомления** — для отображения статуса подключения в шторке.
- **Автозапуск при загрузке** (опционально, если включено в настройках) —
  чтобы восстановить подключение после перезагрузки устройства.

Приложение не запрашивает доступ к контактам, сообщениям, камере,
микрофону или геолокации.
